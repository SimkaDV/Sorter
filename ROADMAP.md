# Роадмап 3D Models Sorter

Один этап — один чат. Скопируй промпт этапа в новый чат Claude Code, открытый в папке `~/Sorter`.
Каждый этап заканчивается рабочим состоянием и коммитом. Подробности — в [SPEC.md](SPEC.md), правила кода — в `CLAUDE.md` (появится на этапе 0).

**Главное правило всех этапов:** разработка и тесты идут только на копии `~/Sorter-testdata/`. Реальную папку `~/3D models ` не трогаем до этапа 9, и там — только по твоей явной команде.

1. Установить **Xcode** из App Store (сейчас на маке только Command Line Tools).
2. Запустить Xcode один раз, принять лицензию, дождаться установки компонентов.
3. В Терминале (попросит пароль):
   ```bash
   sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
   ```
